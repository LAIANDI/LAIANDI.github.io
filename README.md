## 来源

博客源码（文章、配置、图片）保存在私有仓库 `LAIANDI/blog`，使用 **Hexo 7 + Butterfly 5** 构建。

发布流程：

```bash
# 在源码仓库中执行
npm run clean
npm run build
npm run deploy
```

`hexo deploy` 会把 `public/` 的生成结果推送到本仓库的 `main` 分支，GitHub Pages 随后自动更新站点。
