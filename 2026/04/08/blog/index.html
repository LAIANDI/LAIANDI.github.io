发表于2026-04-08|更新于2026-11-25|blog
|浏览量:

这个博客用 Hexo + Butterfly 搭建，源码托管在 GitHub，构建结果发布到 GitHub Pages。这篇文章把从环境准备、主题配置、写作、加密到部署的完整流程整理了一遍，既是给自己的备忘，也希望能帮到同样想搭博客的人。

线上地址：https://laiandi.github.io

一、为什么选 Hexo

静态博客的好处是简单、快、好迁移：

  • 文章就是 Markdown 文件，放在 Git 里，换电脑也不怕丢；
  • 生成的是纯静态 HTML，不需要数据库和后台；
  • 主题生态成熟，Butterfly 的颜值和配置项都很够用；
  • 可以部署在 GitHub Pages，也可以随时搬到自己的服务器。

整套结构是「两个仓库」：

仓库 作用
LAIANDI/blog 博客源码：文章、配置、图片
LAIANDI/LAIANDI.github.io 构建产物，GitHub Pages 从这里读取

十、可选：部署到自己的服务器

GitHub Pages 免费省心，但国内访问速度一般。也可以把 public/ 上传到自己的服务器。

服务器和域名我都是在阿里云买的，中间踩过几个坑：

  • 宝塔面板默认端口是 8888，需要在安全组里放行；
  • 面板登录不上时，先检查端口和代理；
  • 域名解析到国内服务器需要备案，前后大概十几天。

宝塔里新建站点后，把本地生成的静态文件传上去：

也可以在宝塔的「文件」页面手动上传。

HTTPS 用宝塔自带的 Let’s Encrypt 免费证书：

  1. 进入站点设置 → SSL；
  2. 申请 Let’s Encrypt 证书；
  3. 同时勾选带 www 和不带 www 的域名；
  4. 部署证书并放行 443 端口。

服务器安全方面，建议只对外开放 80 和 443，把 22（SSH）、8888（宝塔）限制为自己的 IP，不用的 FTP、phpMyAdmin 端口直接关掉。

十一、图片与性能

博客里最容易把仓库撑大的就是图片。几条经验：

  • 优先用 JPG / WebP，截图里的纯色大图可以转成 WebP；
  • PNG 适合图标、透明背景和壁纸，但 20MB 的 PNG 一定要压缩；
  • 装饰性背景可以手写 SVG，几 KB 就能做到任意分辨率；
  • 图片按文章分目录存放，例如 source/img/ctfshow/pwn71/，方便清理；
  • 文章里的图片加 loading="lazy"，首屏会轻很多。

仓库体积可以直接看 GitHub 的 Insights，超过 100MB 时 clone 会明显变慢。

十二、常见问题

改了配置没生效

首页文章排序不对

检查 Front Matter 里的 date，以及 _config.yml 的 timezone 是否设置正确。

部署后资源 404

GitHub Pages 有 CDN 缓存，刚上传的图片可能短暂 404。可以加版本参数 ?v=1，或者等几分钟再刷新。

Windows 下 Git 提示 LF/CRLF

npm ci 报错 lockfile 不同步

改过依赖后先在本地执行 npm install，把更新后的 package-lock.json 一起提交。
